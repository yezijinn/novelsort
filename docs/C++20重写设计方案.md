# novel-lines-cpp 设计说明

> 版本日期：2026-10-18
> 目标：纯 C++20 的 TXT 小说章节整理工具。
> 原则：性能优先，内存可控，编辑不丢字。

## 1. 分层

- `src/core`：纯 C++20，不依赖 Qt。
- `src/cli`：命令行批处理入口。
- `src/ui`：Qt5 Widgets 桌面层，仅 C++。
- `tests`：core 单元测试与样本。
- `docs`：设计、性能准则、验收记录与索引。

core 只负责文本、章节与目录数据。
GUI 只负责交互、绘制与文件对话框。

## 2. 核心数据

### 2.1 Chapter

- `title`：完整标题。
- `number`：第一列序号。
- `name`：第二列标题。
- `separator`：两列之间的原分隔符。
- `numbered`：是否可递增编号。
- `excluded_from_numbering`：不参与排序。
- `start_line` / `end_line`：正文源行范围。
- `skip_lines`：导出时跳过的源行，升序去重。
- `extra_body`：划入本章的前置正文区间，升序不重叠。
- `inserted` / `synthetic`：插入章 / 合成前言或全文。
- `renamed` / `level_changed` / `suppressed`：标题重写状态。

### 2.2 其他结构

- `LineRange`：源行半开区间。
- `TextExclusion`：行号与 UTF-8 字节半开区间。
- `TextLoadResult`：文本、编码、警告与错误。
- `ParseOptions` / `ParseResult`：解析参数与结果。

不变量：

- 有编号时 `title == number + separator + name`。
- `skip_lines` 升序无重复。
- `extra_body` 升序、合并且不重叠。
- 章节范围不越过源行数。

## 3. 文本读取

- 一次读入文件。
- 识别 BOM、UTF-8、UTF-16LE/BE、GB18030。
- 换行统一为 LF。
- 严格 UTF-8 优先。
- 严格失败后尝试 GB18030。
- 两者都失败时启用容错。
- 容错仅替换少量坏字节为 `U+FFFD`。
- 坏字节上限约 0.001%。
- 超限仍拒绝，避免误开二进制。
- 正常 GB18030 不产生警告。
- 容错编码保留警告，并在界面与 JSON 中显示。

## 4. 章节解析

- 逐行扫描，先做廉价预筛。
- 识别 `#` 标题、中文章节单位、英文标题与特殊章名。
- `序章`、`前言`、`终章`、`后记` 等按章节处理。
- 目录区去重，不重复计数。
- 首个标题前正文生成「（前言）」。
- 全书无标题生成「（全文）」。
- `--title-lines` 可选，默认关闭。
- 解析结果包含章节、目录行、警告。

## 5. 目录编辑

- 改名：序号与标题两列。
- 改层级：卷 / 章。
- 合并：并入上一章。
- 删除：整章移除，记录删除区间。
- 拆分：按光标行拆分。
- 按当前序号拆分：新章为当前 +1。
- 正文划转：划为上一章 / 下一章。
- 统一编号：阿拉伯 / 中文，可补零。
- 参与排序：无编号章自动取下一个序号。
- 不参与排序：跳过计数，仍可移动。
- 全部恢复原样：回到初始解析状态。

写操作统一维护章节不变量。
失败返回 `false`，不抛异常。

## 6. 渲染与导出

- 按当前章节顺序直接渲染。
- 一次行扫描，跳过标题、目录、删除区间。
- `extra_body` 按源行顺序输出。
- 无效内容按字节区间丢弃。
- TXT 输出 UTF-8、LF、章间一个空行。
- JSON 输出目录、编码、警告与章节信息。
- 导出可到程序位置或用户选择位置。
- 导出成功后记录路径，可打开所在位置。

## 7. 桌面界面

- 左侧目录占满窗口高度，固定宽 380px。
- 右侧为文件工具条、导出工具条与正文预览。
- 两列序号与标题在同一模型列内绘制。
- 列表只绘制可见行。
- 章节行高 32px，行间 1px 分隔线。
- 行拖拽排序，`Alt+↑/↓` 键盘移动。
- 预览只读外观，拦截所有输入。
- 预览支持拖选、定位坏字节、拆分与无效标记。
- 明暗主题持久化。
- 所有应用内对话框按钮使用中文。
- 窗口使用自绘标题栏，亮暗主题一致。

## 8. 撤销与恢复

- 撤销 / 重做覆盖章节编辑。
- 最多 60 步。
- 快照总内存上限 24MB。
- 超限丢弃最旧快照。
- 新编辑清空重做栈。

自动备份：

- 编辑后约 1.5 秒写入恢复文件。
- 持续编辑约每 2 秒更新。
- 备份含章节状态、排序、区间与标记。
- 不复制整本原文。
- 启动时若发现备份，提示恢复或丢弃。
- 正常导出、恢复原样、正常关闭时清理。
- 原文件路径、大小或修改时间变化时拒绝恢复。

## 9. 性能基线

Release、当前机器：

| 场景 | 结果 |
|---|---|
| 8.7MB UTF-8 解析 | 40–76ms |
| 17.7MB GB18030 解析 | 248–251ms |
| 解析峰值内存 | 47.5MB |
| 17.7MB 导出 | 300–360ms |
| 导出峰值内存 | 约 60MB |
| GUI 17.7MB 工作集 | 约 65MB |

主链路保持 O(n)。
不做无数据支持的微优化。

## 10. 验证与限制

当前验证：

- core 2090 checks / 0 failures。
- GUI 56/56 PASS。
- ctest 3/3。
- 编译 0 warning。

限制：

- 仅 TXT。
- GB18030 解码仅 Windows。
- 容错比例超过约 0.001% 时拒绝。
- 预览单章最多显示 5 万字。
- 自动备份只保留一份。
- 原 TXT 变化后不能安全恢复。
- 无跨会话撤销。
- 无原生 Snap 与窗口几何记忆。
