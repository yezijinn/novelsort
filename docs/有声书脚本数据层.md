# 有声书脚本数据层

## 目标

把已解析的章节文本切成可朗读片段。
保留原文位置，供后续归属、校对和语音合成使用。
当前只做确定性切分，不接解析服务，不生成音频。

## 输出

单文件 UTF-8 JSON，单行。
顶层字段：

| 字段 | 说明 |
|---|---|
| `schema` | 固定 `novelsort/script/1` |
| `offset_unit` | 固定 `utf8_byte` |
| `source` | 输入路径 |
| `encoding` | 识别到的编码 |
| `characters` | 角色表；当前只有旁白 |
| `chapters` | 章节与原文范围 |
| `segments` | 切分片段 |

片段字段：

| 字段 | 说明 |
|---|---|
| `id` | 全文连续编号，从 1 开始 |
| `chapter` | 章节编号，从 1 开始 |
| `type` | `heading` / `narration` / `dialogue` / `thought` |
| `speaker_id` | 旁白固定 `narrator`；对白和心声暂为 `null` |
| `speaker_hint` | 归属语候选，可能为空，不是最终说话人 |
| `text` | 源文本精确子串 |
| `speak_text` | 去外层引号、换行压空格后的朗读文本 |
| `source_start` / `source_end` | 解码并统一 LF 后的 UTF-8 字节偏移，半开区间 |
| `emotion` / `tone` | 预留；当前为 `null` |
| `confidence` | 结构置信度 |
| `needs_review` | 引号未闭合等需人工确认的情况 |

## 切分规则

- 非合成章：标题行输出 `heading`，正文从下一行开始。
- 合成章或插入章：不输出标题片段，正文从起始行开始。
- 目录区行不进入正文。
- 非合成章正文里的目录样式文本按正文保留。
- 引号对支持 `“”`、`「」`、`『』`、`‘’`、ASCII `"`。
- 支持跨行与嵌套引号；外层引号内整体归为一个片段。
- 引号外文字归 `narration`。
- 引号前出现「心想、暗道、心中想、暗想、寻思、心里想、脑海里、内心」时归 `thought`。
- 未闭合引号仍输出 `dialogue`，`confidence=0.30`，`needs_review=true`。
- `speaker_hint` 只做低级线索：在引号前后找言语动词，取动词前的 2–3 字候选；只接受常见姓氏开头或代词。找不到时留空。

## 校验

`validate_script` 检查：

- `id` 连续。
- `chapter` 在范围内。
- `source_start < source_end`，且不越界。
- 偏移基于解码、统一换行后的文本，不是原始文件字节。
- `text` 与源文本对应区间逐字节一致。
- 同一章内片段不重叠、按原文顺序。
- 非合成章的片段间隙只能含空白。

## 命令行

```powershell
novellines-cli --input book.txt --script script.json
novellines-cli --input book.txt --script script.json --move 10:1
novellines-cli --input book.txt --script script.json --dry-run
```

`--script` 可与 `--out`、`--json` 并用。
`--dry-run` 打印片段统计，不写文件。

## 桌面入口

桌面端左侧菜单有两页：

- 章节整理：原章节识别、重排与目录导出。
- 台词拆分：打开 TXT，按章列出章节；点章查看该章片段与详情，导出脚本 JSON。

`--page dialogue` 可让桌面端直接打开台词拆分页。

## 当前限制

- `speaker_hint` 是启发式候选，含少量错误；不能替代最终说话人标注。
- `speaker_id` 只填旁白；对白与心声留空。
- `emotion` / `tone` 未实现。
- `speak_text` 只做去外层引号与空白压缩，不做数字、称谓、专名改写。
- 只覆盖 TXT 输入。
- 合成章允许跳过目录行，间隙校验相应放宽。
